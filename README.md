# 文明小桌 · 桌游版文明

一局二十回合的桌游版文明小游戏。没有操作门槛：每回合只需要**点格子扩张、点卡片建造或研究、点「结束回合」**，五到十分钟一局，适合日常碎片时间。

同一套规则引擎跑在三个地方：

| 目录 | 说明 |
| --- | --- |
| `miniprogram/` | 微信小程序（原生 WXML，开始页 + 对局页） |
| `miniprogram/engine/civ-engine.js` | 核心规则引擎，零依赖，小程序 / 浏览器 / Node 共用 |
| `web/` | 网页版，与小程序同样的界面，便于在浏览器里试玩和调试 |
| `dist/civ-board.html` | 网页版单文件打包，双击即可玩 |
| `test/` | 规则测试（`node:test`） |
| `scripts/` | 打包与平衡性模拟脚本 |

## 玩法

- **棋盘**：8×8 格，平原🌾 / 森林🌲 / 山地⛰️ / 河谷🏞️ / 沙漠🏜️ / 海洋🌊 / 遗迹🏺 / 自然奇观🗻，每种地形产出不同。
- **三种资源 + 分数**：🌾粮食用于扩张，⚒️生产用于建筑和奇观，🔬科技用于研究，🎭文化就是分数。
- **一回合**：先自动收入，再做最多 3 次行动，然后点「结束回合」。电脑对手瞬间走完。
- **越多越贵**：领土、建筑、科技的造价都随已有数量上涨，所以要有取舍。
- **时代**：研究完当前时代的 3 项科技进入下一时代（远古 → 古典 → 中世纪 → 文艺复兴 → 工业），解锁新建筑和奇观。
- **奇观**：全场唯一，谁先建成归谁，每座 +5 分。
- **事件卡**：每 3 回合翻开一张（丰收、瘟疫、蛮族来袭……），影响所有文明；城墙或长城可免疫蛮族。
- **结算**：20 回合后，分数 = 领土×1 + 建筑×2 + 科技×2 + 奇观×5 + 文化，最高者获胜。

**六个文明**：华夏（科技）、罗马（扩张）、埃及（奇观）、希腊（文化）、波斯（生产）、印加（山地），各有一条被动特色。

**三种对局**：每日一局（当天所有人同一张地图，记录今日最佳）、随机地图、多人同机（2～4 人传手机轮流玩）。电脑强度分轻松 / 普通 / 困难。

## 在微信开发者工具里打开

1. 安装[微信开发者工具](https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html)。
2. 「导入项目」，目录选择本仓库根目录（`project.config.json` 所在处），AppID 可先用「测试号」或保持 `touristappid`。
3. 编译后即可在模拟器里玩；真机预览用右上角「预览」扫码。
4. 要正式发布时，把 `project.config.json` 里的 `appid` 换成你自己的小程序 AppID。

整个小程序没有任何网络请求与图片资源（图标全部用 emoji），存档在本机 `wx.storage`。

## 网页版

```bash
npm run build:web      # 生成 dist/civ-board.html（单文件）
npm run serve:web      # 或者本地起服务访问 web/index.html
```

`dist/civ-board.html` 可以直接用浏览器打开，手机、电脑都适配，支持深色模式。

## 开发

```bash
npm test               # 规则测试
npm run sim            # 让 4 个电脑互打 300 局，输出平衡性统计
```

引擎对外只暴露几个函数：`createGame`、`getView`（给 UI 的完整视图模型）、`applyAction`、`endTurn`、`ackEvent`、`serialize` / `load`。UI 层不需要理解规则，照着视图模型渲染即可，因此小程序和网页版的页面代码都很薄。

当前平衡（4 个电脑互打 300 局）：平均每人领土 12～13 格、研究 8 项科技、建 8 栋建筑、1～2 座奇观，总分 110 左右；六个文明胜率都在 20%～30% 之间。
